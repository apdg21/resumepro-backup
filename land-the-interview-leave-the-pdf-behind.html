FAQ

Quick answers.

What's the difference between publishing and downloading?
Publishing goes live straight from the AI builder — happy with the preview? Publish and you have a shareable link, no setup at all. Downloading gives you the full site as a ZIP to host wherever you like: GitHub Pages, Netlify, or any standard web host. Same $15 key covers both, and the templates you buy for $10 are downloadable files you can host anywhere too.
Do I need coding skills to use these templates?
No coding skills required! The templates come with simple editable files — just replace the placeholder text using the built-in form, or let the AI builder fill everything for you. The templates handle all the design and layout automatically.
How do I host my digital resume?
Two options. Publish straight from the AI builder for an instant link, or download the full site and host it yourself — every download includes detailed instructions for free hosting like GitHub Pages and Netlify, and it works on any standard web host with no special server requirements.
Can I customize the colors and fonts?
Absolutely! Open style.css in any text editor and change the color variables at the top — every template includes a Template_Guide with step-by-step instructions.
What's included in the template download?
A ZIP file with all HTML, CSS and JavaScript files, a simple data file to edit your information, detailed setup instructions, and bonus tips for optimizing your digital resume.
Is this a subscription or a one-time payment?
Everything is one-time: $10 per template with lifetime access (plus free updates for one year), or a $15 key that unlocks unlimited use of the AI builder — re-run it any time your resume changes. No subscriptions, ever.
